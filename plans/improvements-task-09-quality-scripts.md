# Task 09: Add quality scripts to package.json

## Goal
Expose basic quality checks via scripts.

## Scope
- Add `typecheck` (e.g., `tsc -p .`).
- Add `lint` if configured later.
- Add `test` once tests exist.

## Acceptance Criteria
- `npm run typecheck` (or `bun run typecheck`) works.
- Scripts are documented in README if relevant.

## Files
- `package.json`
- `README.md` (optional)
